# QuickSkip (闪跳) - 极简开源 Android 开屏广告自动跳过工具

专为 Android / 小米 HyperOS 定制的超轻量开屏广告跳过工具。

## ✨ 特性

- **🔒 零网络权限**：完全不申请 `INTERNET` 权限，从物理层面杜绝任何数据回传与隐私风险。
- **⚡ 毫秒级响应**：基于 Android 原生 `AccessibilityService`，支持精准节点文本正则过滤（支持“跳过”、“Skip”、“3s 跳过”等）。
- **🎯 手势兼容**：针对无法通过原生无障碍点击事件触发的顽固广告，提供 Android 7.0+ 坐标手势回退模拟点击。
- **🔋 超低耗电**：无常驻后台轮询死循环，仅在窗口切换及内容变化时触发事件。
- **☁️ 云端自动构建**：内置 GitHub Actions，代码提交后自动打包生成 APK。

## 📱 小米 HyperOS / MIUI 运行指引

为了确保在小米系统后台长期稳定生效，请务必设置：
1. **开启无障碍服务**：设置 -> 更多设置 -> 无障碍 -> 已下载的服务 -> 开启 QuickSkip。
2. **应用自启动**：允许自启动。
3. **省电策略**：设置为“无限制”。
4. **后台卡片加锁**：多任务界面长按卡片加锁。
